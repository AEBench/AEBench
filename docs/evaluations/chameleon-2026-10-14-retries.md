# Chameleon follow-up trials — 2026-10-14

The [original 30-trial record](chameleon-2026-10-14.md) remains unchanged. This follow-up records 40 completed clean Codex trials for cases that did not reach 4/4. The upstream artifacts were not edited. Each retry has a private Swift archive and manifest; the [machine-readable index](chameleon-2026-10-14-retries.json) includes outcomes, environment interventions, exact revisions, and SHA-256 pointers. Credential-redacted trajectory exports are on a [separate branch of the private evaluation repository](https://github.com/AEBench/aebench_eval_traj/tree/muneeb/chameleon-codex-trajectories-20261014); raw archives and signed URLs remain private.

The interventions target observed harness or host problems. Calchas needed Python analysis packages in its derived agent image. SeBS-Flow needed those packages in the AEBench virtual environment, plus task guidance to calculate all four metric groups from released measurements. DepSurf needed AEBench oracle paths corrected for the upstream checkout layout in [PR #132](https://github.com/AEBench/AEBench/pull/132), stacked on provisional PR #129. Paralegal and WALI needed local analysis packages visible inside AEBench's virtual environment. ICEmu and Wasabi had their AEBench Docker snapshot timeout raised from 60 to 900 seconds. ACTO needed pinned Go, kind, and kubectl host dependencies. These changes did not change artifact source or oracle scoring thresholds.

Three clean 4/4 follow-ups are verified for Calchas (4–6), ICEmu (4–6), DepSurf (4–6), SeBS-Flow (7–9), Paralegal (7, 10, 11), and WALI (8, 10, 11). Paralegal's pinned CodeQL 2.19.3 was exposed on the host PATH for its final two successful trials. WALI's evaluator needed its Python packages in the AEBench virtual environment and genuine syscall traces from `iwasm -v=4`. ACTO scored 4/4, 3/4, and 2/4 in its three follow-ups; its two lower-scoring trajectories need further analysis. EET and Wasabi each repeated 1/4 in three follow-ups, including nested Codex safety refusals; no safety bypass was attempted. All lower scores and their phase outcomes remain in the JSON index.

A result below 4/4 is preserved as a trial result, not overwritten by later attempts. DepSurf and EET remain provisional while PR #129 is unmerged. Every indexed archive was downloaded and checksum-verified before publication.
